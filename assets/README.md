# Assets Folder

## Icon File

Place your app icon here as `icon.png` (256x256 or 512x512 recommended).

### Quick Icon Options:

1. **Create Online**: Use https://favicon.io/favicon-generator/ or https://www.canva.com
2. **Use Emoji**: Convert a 💰 or 📊 emoji to PNG
3. **Download Free**: https://icons8.com or https://www.flaticon.com

### Recommended Specs:
- **Format**: PNG with transparency
- **Size**: 256x256 or 512x512 pixels
- **Name**: `icon.png`

The app will run fine without an icon - it's purely cosmetic!
