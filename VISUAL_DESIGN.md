## UI Components

### Stat Card
```
┌─────────────────────┐
│ TOTAL EXPENSES      │ ← Label (muted, uppercase)
│                     │
│ ₹4,200              │ ← Value (large, bold)
│                     │
│ ↑ This Year         │ ← Change indicator
└─────────────────────┘
  ▲
  └─ Top border (gradient)
```

### Navigation Item
```
┌────────────────────┐
│ │ 📊  Dashboard    │ ← Active (highlighted)
│ │ 🚗  Vehicle      │ ← Inactive
│ │ 🎮  Games        │ ← Hover state
└────────────────────┘
  ▲
  └─ Active indicator (left border)
```

### Button States
```
Default:   [  Add Entry  ]
Hover:     [  Add Entry  ] ↑ (lifted)
Active:    [  Add Entry  ] (pressed)
Disabled:  [  Add Entry  ] (grayed)
```

### Toggle Switch
```
OFF:  ○────  (gray)
ON:   ────○  (purple gradient)
```

## Animations

### Login Screen
```
1. Background dots move infinitely
2. Login box slides up + fades in
3. Icon pulses with glow
```

### Page Transitions
```
1. Fade out current content
2. Fade in new content
3. Charts animate on render
```

### Card Hover
```
Default:  [Card]
Hover:    [Card] ↑ + shadow glow
```

### Chart Animations
```
Line Chart:  Draws from left to right
Doughnut:    Rotates in clockwise
```
